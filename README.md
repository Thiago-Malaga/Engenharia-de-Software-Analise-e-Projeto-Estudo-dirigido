# Protótipo: Aplicativo de Estacionamento
Ele cobre o Requisito 1 (Visualização em tempo real) e o Requisito 2 (Prevenção de vagas reservadas).
Também atende parcialmente ao Requisito 3 (Dados em cache) salvando o histórico em um arquivo CSV.
O sistema exige login (aluno/servidor) apenas para validar o acesso às vagas exclusivas próximas à biblioteca.
**Como executar o protótipo:**
1. Certifique-se de ter o Python 3 instalado no seu computador.
2. Abra o terminal no diretório do projeto e execute: `python nome_do_arquivo.py`
3. Siga o fluxo na tela para fazer login informando se você é "aluno" ou "servidor".
4. Interaja digitando a coordenada e a ação (ex: `A1 ocupar`) e digite `sair` para salvar e fechar.
